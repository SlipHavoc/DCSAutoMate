## Indicators

49 indicators total. Extracted from `device_init.lua` utilizing standard lupa execution and mocks.

Many page files (all overhead gauges, AMU, CNI, CNBP, HUD) name their text elements with `create_guid_string()`, a DCS engine function. At runtime DCS assigns a random GUID per session (e.g. `{1AD8202D-B9C1-...}`), so these field names cannot be mapped. The extractor mocks it to return `guid-N` placeholders so the pages load fully; the generator skips `guid-N` fields but still emits the `ind.<id>` aggregate entry, which returns all non-empty field values joined by newlines. For single-field gauges this is just the displayed value:

- `ind.33` — APU NG (RPM %), `Overhead/init_apu_ng.lua`
- `ind.34` — APU EGT, `Overhead/init_apu_egt.lua`

Before the mock, these pages errored at the first `create_guid_string()` call, which silently dropped the indicator (and any named fields defined after the call).

## Mapping Customizations

To mirror the actual physical behavior of cockpit controls, some helper mappings use tailored archetypes:
- **Momentary HUD Buttons (`hud_btn`):** Clamped functional boundaries to `[0.0, 0.25]` with a single step, rather than 5 positions, to eliminate deep pseudo-press states in the model.
- **Oxygen Diluter and Squelch Switches (`oxygen_switch`):** Elevated the canonical `argLim` to `[-2.0, 2.0]` with step `4.0`, representing two direct states (`ON` and `OFF`). This eliminated the need for `indicatorArgLim` workarounds and simplified control interaction in UI.
- **Fire Handles (`customFirePull`):** Maps fire pulls to discrete 2-position controls. Note that rotational extinguisher commands are locked until the corresponding handles are physically pulled out.
