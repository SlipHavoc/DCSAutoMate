## Category A — Autothrottle Disconnect Draw Argument (EXPECTED)

**Control:** `AP_INTERFACE.cmd_3036` (Right Autothrottle Disconnect Button)

The right autothrottle disconnect button's visual draw argument element (arg `20`) is shared and dynamically overridden by the animation position of the Right Throttle Lever itself in the C-130J cockpit art. When read back, it registers the throttle's physical angle (`0.7230` to `0.7231` throttle state) rather than the button press-state. This is an expected animation limitation in the DCS cockpit. **Acknowledged as expected.**

## Category B — Fire Extinguisher Handle Rotation Mechanical Locks (EXPECTED)

**Controls:**
- `ENGINE_APU_CTRL.apu_fire`
- `ENGINE_APU_CTRL.engine_1_fire`
- `ENGINE_APU_CTRL.engine_2_fire`
- `ENGINE_APU_CTRL.engine_3_fire`
- `ENGINE_APU_CTRL.engine_4_fire`

In the real C-130J-30 aircraft and the DCS module simulation, the fire extinguisher handles cannot turn until the corresponding fire handle has been physically pulled out. Since the automated validation sweep tests controls starting from cold-and-dark stowed positions, the handles are pushed in; hence, physical mechanical locks prevent them from rotating and the arguments stay stuck at `0.0000`. **Acknowledged as expected.**

## Category C — Microwave Button 3 Draw Argument Typo (EXPECTED)

**Control:** `GALLEY.micro_3` (Microwave - 3 Key)

The command behaves correctly on the device, but the 3D cockpit model misses a draw instruction mapper for arg `1655` (it stays at `0.0000` when pressed). All other microwave keys (0, 1, 2, 4, 5, 6, 7, 8, 9, clear, start) work and pass perfectly, proving that the underlying helper class and device actions are flawless. **Acknowledged as expected.**
