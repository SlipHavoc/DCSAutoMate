## Known State-Dependent Indication Fields

The A-10C has very large indicator field sets. Most fields are only populated
when the corresponding display page is active:

- **ind.1 / ind.2 (MFD, 727 fields each)** — only fields for the currently
  displayed MFD page will be non-empty. Many fields will return empty during
  any given validation run depending on which page is shown.
- **ind.3 (CDU, 1322 fields)** — fields for the current CDU page only. Confirmed
  live via diagnostic scripts (2026-05-02): returns 30 populated fields at a time
  on the CDU NAV page during a typical flight.
- **ind.5 (HUD, 1137 fields)** — HUD mode-dependent. Many symbology elements
  only appear in specific master modes (NAV/AA/AG).
- **ind.6 (AN/ALR-69V RWR, 137 fields)** — threat-dependent. Most fields will
  be empty with no radar environment present.

For practical scripting, use the aggregate controls (`ind.3`, `ind.7`, `ind.10`,
etc.) to check display content without needing to know the active page.

## Caution Lamp Panel

71 caution/warning lamps mapped via `SystemsSignals` reverse-map (args 178–737).
These are arg-based controls with `[0, 1]` input/output range:
- `0.0` = lamp off
- `1.0` = lamp on (caution active)

All flag names use the verbatim `flag_*` prefix from `SystemsSignals` in
`mainpanel_init.lua` (e.g. `arg.484` → `flag_ANTISKID`).

During validation, all caution lamps will likely read `0.0` (off) in a normal
hot-start active-pause state. This is correct — no validation failures expected
for these controls.

## UHF Radio Displays (ind.10–13)

## Expected Validation Issues

These are anticipated based on patterns seen in other modules; confirm during
first live run:

- **Guarded controls** — some emergency/jettison switches may be behind covers.
  With guard auto-opening enabled they should pass; confirm which guards are
  present.
- **Ejection seat handle** — likely physically blocked (one-shot irreversible
  in DCS). Expected validation skip or failure.
- **Large indication field counts** — validation will attempt all 4181 per-field
  indication reads. The MFD/CDU/HUD fields will produce many empty returns for
  non-active pages. These are not errors — the fields exist, they just have no
  current value. Validation should report them as pass (empty string is a valid
  value), not as failures.
