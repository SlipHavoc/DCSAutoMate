## Known failures (6)

### Continuous / relative readback scale mismatches (3)

These controls move, or are commandable, but the live cockpit arg readback does not match the generator's current send range exactly.

- `ADI.IKP-TANGAGE-PTR` - expected `[-1.0, 1.0]`; DCS readback clamps around `[-0.2618, 0.2618]`. This looks like the device converts the clickable input to a smaller physical pitch-trim range.
- `CLOCK.CLOCK-RIGHT-LEVER-PTR_arg525` - expected `[-0.15, 0.15]`; observed `[0.0, 0.15]`. The negative half of the range did not appear in this cockpit state.
- `CLOCK.CLOCK-LEFT-LEVER-PTR_arg511` - relative increment had no effect from the tested state.

### Cover / guarded switch timing or toggle behavior (3)

These are `animated_guard_switch` style covers. They are real covers, and several settle slowly or report intermediate animation values at the default delay.

- `EJECT_SYS_INTERFACE.RIGHT-COVER-EMERG-VACATION-PTR` - position 0 read back as `0.2999` instead of `0.0`.
- `ELEC_INTERFACE.ENERG-COVER-AER-RIT-PTR` - position 0 read back as `0.1499` instead of `0.0`.
- `UV_26.UV26-POWER-COVER-PTR` - position 0 read back as `0.1499` instead of `0.0`.

## Skips (108)

Most skips are indication/display fields that are not currently emitted by `list_indication()` in this cockpit state, which is normal for state-dependent HUD, Shkval, PVI, and auxiliary displays.

The first four skips are R-800 frequency wheels with `arg=-1` pure encoder mappings; they have no readable cockpit position and are intentionally skipped by the validator.

## Discrete indicators

The regenerated mapping added 46 `indicatorArgLim` annotations. Most are PVI, datalink, autopilot, caution, weapon, and engine controls where DCS writes the actual indicated state back to the same arg slot used for the command. Those controls should not be interpreted as ordinary discrete controls: command values and readback values intentionally use different scales.

Validation confirms the important behavior: these controls pass as indicator-range controls, with details like `2 positions OK (indicator-range; exact value not verified)`.
